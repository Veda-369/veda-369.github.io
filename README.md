- **Contact** — LinkedIn and GitHub

## Photography Gallery

The photography gallery reads images from the public `/photos` folder and automatically adapts each frame to the image's natural orientation.

Supported formats:

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`

New photos can be added directly to the `/photos` folder without changing the gallery layout. Existing numbered filenames and duplicate-style filenames are supported.

Known locations and captions are maintained in the photography metadata. New captions can be added whenever additional photo details are available.

## Deployment

This site is designed for GitHub Pages. Push the portfolio files to the repository's publishing branch and GitHub Pages will serve the site.
