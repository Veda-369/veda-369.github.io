02
Independent projectTransportation · Spatial analytics

UDOT SafeCorridor Intelligence

An independent exposure-adjusted roadway-safety prioritization and decision-support system built from public Utah transportation data.

449,804crash records processed
96.5%eligible crash-to-AADT match rate
519five-mile corridors tested
45supported corridor clusters

Case addressed

  • Raw severe-crash counts do not account for how much traffic exposure a roadway carries.
  • The project asks which corridors show unusually high fatal and serious-injury burden after exposure adjustment.
  • It also separates prioritization signals from causal claims and documents limitations explicitly.

What I built

  • Python ingestion from public UDOT sources with schema normalization and Parquet persistence.
  • Spatial route matching, linear referencing, five-mile corridor construction, and exposure adjustment.
  • Observed-vs-expected screening with Poisson uncertainty and Benjamini-Hochberg false-discovery-rate control.
  • A Streamlit dashboard with statewide exploration, priority corridor screening, drill-down, and methodology views.

Technology

  • Python, SQL, DuckDB, Pandas, GeoPandas, Shapely, SciPy, Parquet, ArcGIS REST.
  • Streamlit, Altair, PyDeck, and GitHub Actions.
  • Bronze → Silver → Gold analytical transformations with automated QA outputs.

What changed

  • Crash location, exposure, geometry, uncertainty, and corridor consolidation became one reproducible analytical chain.
  • The workflow achieved a 99.0% valid spatial route-match rate and 0.29 m median snap distance.
  • A weekly GitHub Actions pipeline can refresh the published analytical outputs automatically.
